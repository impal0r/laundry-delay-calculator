Mode

Delay settings can work differently on different washing machines. Some machines let you set the delay until the cycle starts, while others let you choose how long it should take before the cycle finishes.

Delay start: set how long to wait before the cycle starts.
Delay end: set how long until the cycle finishes.

Use the Rounding dropdown to choose how precise you want the delay setting.
